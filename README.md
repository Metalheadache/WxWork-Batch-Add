# 企微批量添加助手（WxWork Batch Add）

一个在 **Windows 桌面版企业微信** 上批量添加外部联系人的小工具。导入一批手机号，它会逐个搜索、自动判断三种结果（已是好友 / 可添加 / 无微信），按你的设置打标签、发送带自定义验证语的好友请求，并把每个号码的处理结果写回文件。

它不调用任何企业微信接口，也不读取聊天数据，只是**模拟人手在官方客户端上点击**——相当于一个替你重复点鼠标的机器人。

> ⚠️ 请先读文末的「合规与风险」。批量加好友属于敏感操作，用不好会触发企业微信频控甚至封号，请务必控制频率、确保对方是你有正当理由联系的客户。

---

## 它能做什么

- 从一个 txt 文件批量导入手机号（每行一个 11 位号码）。
- 逐个号码自动处理，识别三种情形：
  - **已是好友** → 标记「已是好友」，跳过。
  - **可添加**（非好友）→ 可选打标签 → 发送带自定义验证语的好友请求 → 标记「已发送好友请求」。
  - **无微信信息**（搜索报「该用户不存在」）→ 标记「手机号码无微信信息」。
- 可选「打标签」：给新加的联系人自动加上你指定的一个已有标签。
- 自定义好友验证语。
- 安全阀：单次运行发满 N 条好友请求自动停；每个号码之间随机停顿；连续遇到不认识的界面自动停并留截图。
- 断点续跑：处理结果实时写回文件，随时中断都不丢；重跑自动跳过已处理的号码。

## 为什么要「校准」（重要）

程序靠**图像识别**来认界面上的按钮。默认内置的按钮图是在某一台机器上截的（深色主题、2560×1440、系统缩放 150%）。如果你的**主题、分辨率、缩放、企业微信版本或语言**和它不同，默认图就对不上，程序会认不出按钮。

解决办法是内置的**校准向导**：它让你在自己的屏幕上，一个个框选出「添加为联系人」「发送」等按钮，存成你专属的模板。之后程序就用你的图来识别，主题深浅、分辨率高低、版本新旧都不再是问题。**换了电脑、换了主题、企业微信大版本更新后，重新校准一次即可。**

## 安装与运行

### 方式一：直接下载 exe（推荐给非开发者）

到本仓库的 **Releases** 页面下载最新的 `WxWorkBatchAdd.exe`，双击即可运行，无需安装 Python。

（这些 exe 由 GitHub Actions 在 Windows 上自动编译，源码见仓库，可自行核对。）

### 方式二：从源码运行

需要 Python 3.9 及以上（Windows）。

```bat
git clone https://github.com/Metalheadache/WxWork-Batch-Add.git
cd wxwork-batch-add
pip install -r requirements.txt
python src/main.py
```

### 方式三：自己打包 exe

```bat
build.bat
```

完成后 exe 在 `dist\WxWorkBatchAdd.exe`。

## 使用步骤

1. **打开企业微信**，进入 `通讯录 → 新的客户 → 右上角「添加」`，让「添加客户」搜索弹窗停在屏幕上。
2. **打开本程序**，按界面从上到下设置：
   1. 选择号码 txt 文件；
   2. （可选）勾选「打标签」并填写标签名称（该标签需已在企业微信里建好）；
   3. 填写好友验证语；
   4. 设置单次上限与间隔（建议 ≥ 8 秒、每天 ≤ 100 条）。
3. **首次使用先点「校准向导」**，按提示从自己的屏幕框选各个按钮。若你的环境恰好和内置模板一致，也可以点「自检模板」直接开始。
4. 点 **「试跑 3 个」** 先验证流程无误（会在 `debug` 文件夹留每步截图）。
5. 确认无误后点 **「▶ 开始」**。运行期间**不要动鼠标键盘**。
6. 需要停下时点 **「■ 停止」**，或把**鼠标猛甩到屏幕左上角**紧急停止。

## 号码文件格式

纯文本 txt，每行一个 11 位手机号：

```
15578985281
13361962335
15221484028
```

处理后，程序会在号码后面用 Tab 追加结果：

```
15578985281	已是好友
13361962335	已发送好友请求
15221484028	手机号码无微信信息
```

没有标记的行表示还没处理（或上次遇到未知状态待重试）。第二天直接重跑，已标记的行会自动跳过。

## 结果标记含义

| 标记 | 含义 |
|---|---|
| 已是好友 | 对方已在你的联系人里 |
| 已发送好友请求 | 已（按设置打标签并）发送验证语 |
| 手机号码无微信信息 | 搜索提示「该用户不存在」 |
| （空白） | 未处理 / 上次未知状态，重跑会重试 |

## 频控与账号安全

企业微信对加好友有严格频率限制，短时间大量发送极易触发风控，轻则功能冻结、重则封号。请务必：

- 单次、单日都控制数量（默认单次上限 100，建议新号更低）。
- 间隔别调太低（默认 8–15 秒随机，别改小）。
- 一旦企业微信开始频繁弹「操作频繁」，当天就停手，隔天再跑。

这些默认值是保守起点，不是安全承诺。你对自己账号的行为负责。

## 常见问题

**Q：一直提示「未知界面」并停下？**
多半是界面和模板对不上，或触发了频控。先看 `debug` 文件夹里的截图：如果是频控提示，今天别跑了；如果是按钮位置/样式变了，重新跑一次「校准向导」。

**Q：打标签总失败？**
确认标签名和企业微信里的完全一致、且该标签已存在。换了标签名建议重新校准「第一个标签」这一项。

**Q：换了电脑/改了主题后全都认不出？**
重新运行「校准向导」采集当前环境的模板即可。

**Q：多显示器能用吗？**
目前只支持在**主显示器**上操作，请把企业微信放到主屏。

## 开发说明

```
src/
  main.py         入口
  gui.py          图形界面(tkinter)
  engine.py       自动化引擎(三情形判定、打标签、发请求、写回)
  matcher.py      多尺度、DPI 感知的模板匹配
  calibration.py  校准向导(从用户自己屏幕采集模板)
  config.py       配置与路径
  manifest.py     模板清单(校准与引擎的单一事实来源)
  templates/default/  内置默认模板 + geometry.json
```

配置保存在 exe 同级目录的 `config.json`；日志 `run.log`;异常截图 `debug/`;校准模板 `custom_templates/`（源码运行时为 `src/templates/custom/`）。
